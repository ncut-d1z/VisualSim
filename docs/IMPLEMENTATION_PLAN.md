## 2. 需求决策冻结

以下事项**已由用户决定，后续实施不再要求重复审批**：

1. Ubuntu 24.04 Linux-only，**Windows 禁止构建**；不强制降低现有可用工具链版本。
2. 无 ROS；Eigen、Sophus、OpenCV 等非 ROS 第三方依赖允许使用。
3. 轨迹由**函数调用或配置文件**定义，不在源码中硬编码仅有的两条运动轨迹。
4. OpenGL Immediate Mode 风格：BeginMotionMode 和 **EndMotionEnd**；两大类别（线、角）可跨类组合，不可类内组合，新同类模式覆盖当前值，出栈恢复以前的模式与参数。
5. 按变更时间保存**模式、参数、传感器标定、相机创建/改名、Room 变量**的所有修改记录；查询历史按这些事件分段重新解析积分。
6. **不允许缓存任何历史帧/位姿/IMU/交点或最近 64 组图像位姿**；仅维护配置/命令历史和保证生成协议正确所需的最小时间/编号计数器。
7. 动态支持 1..N 台相机；新外参注册自动创建 camX，可改名；无显式创建时默认 cam0 和 (I3,0)。
8. **仅 Room 场景**；删除 ForwardDepthScene 设计和相关场景模式选项。
9. 相机和 IMU 标定必须进入真实数值仿真；IMU 噪声默认关闭，启用后按参数加噪并支持固定种子。
10. 逐传感器严格递增纳秒时间，拒绝重复生成新帧；所有纳秒参数为 std::int64_t。
11. 安装式 Linux 共享库，CMAKE_INSTALL_PREFIX 可指定位置，带消费端示例；原有数据集导出能力保留为按需、配置驱动。

设计层面的必要细化：
- 圆周运动出栈时为了保持 p/R 连续，优先按保存的相对轨道几何在当前位姿重新锚定；对明确要求不可移动世界圆心但与连续性冲突的设置返回错误。
- 既定角运动模式只有静止和**定轴匀速**旋转，段内角加速度为零。非零角加速度需用户另行授权新的角运动模式，不在当前实现范围中暗中增加第三种角模式。

## 5. 文档一致性与禁止事项核对

工程实施过程中，每次涉及公开 API 的修改，必须同时核对 SRS（外部行为）、HLD（组件合同）、LLD（公式与错误条件）和本计划（迁移实施）。不可在 SRS 中加入迁移文件表或源代码实施步骤。

禁止事项：

- 修改 ncut-d1z/ros2-vio-node 仓库；
- 重新引入 ROS 运行时、ament、cv_bridge 或 ROS 消息依赖；
- 重新允许 Windows 编译，或要求为 Ubuntu 24.04 强制降低构建工具链；
- 把固定的两条轨迹硬编码为唯一的轨迹来源；
- 允许类内模式并行叠加，或者将 EndMotionEnd 改名而不兼容用户指定 API；
- 为了求交再引入最近 64 组图像位姿/帧/交点缓存；
- 固定只生成双目、默认创建两台相机或改名后覆盖其他相机；
- 引入 ForwardDepthScene；
- 重复传感器时间生成新帧、新编号；
- setter 只改元数据、不改变真实观测；
- 在采样/查询时未经明确指令写盘、删除文件。
